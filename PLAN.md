# Build plan
1. Record current CMS, FDA, public payer policy patterns, the bundled CKG mapping, and action boundary in docs.
2. Build an offline FastAPI copilot using deterministic, cited graph traversal and a synthetic policy overlay. Keep review acceptance local and append-only.
3. Generate 40 frozen synthetic cases and a distinct test split; implement a naive text retrieval control and report metrics.
4. Add a small page, screenshot, quickstart, tests, and CI gate. Verify happy and fail-closed flows.

This standalone directory is intended to become its own public repository. No real patient or customer data is used.
